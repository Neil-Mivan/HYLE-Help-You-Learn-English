# 澄读 · IELTS Reading

一个隐私优先的英文精读与 AI 翻译工具，面向雅思阅读和日常英文学习。

它可以整理长文章、辅助查询单词和句子、记录高亮与笔记，并把学习数据保存在用户自己的浏览器中。项目无需账号和数据库；需要 AI 能力时，可选接入用户自己的阿里云百炼千问 API。

> 当前版本优先支持 Windows 11。网站在本机运行，不会因为仓库公开而自动部署到互联网。

## 主要功能

### 文章阅读

- 从文章库选择文章并进入专注阅读
- 粘贴英文文章，自动识别标题并整理段落
- 可选使用 AI 识别标题、正文结构和小标题
- 清爽的阅读排版、正文放大与缩小
- 离开阅读页后，通过“继续阅读《文章名》”返回原文并恢复段落位置
- 段落级全文对照翻译

### 翻译与精读

- 独立 AI 翻译页，不进入文章也能查询单词、词组和句子
- 单词查询按词性整理常用义项，并提供例句
- 词组和句子直接生成完整中文翻译
- 点击单词或框选内容，在精读栏中查看翻译
- 按需解释单词在当前语境中为什么这样翻译
- 六词以上的选区可按需进行长难句语法拆解
- 浏览器发音
- 千问不可用时，文章内的普通翻译可尝试使用 Chrome 内置英中翻译能力

### 学习工具

- 三色荧光笔高亮
- 选段笔记和文章笔记
- 生词本与复习记录
- 本地文章库和学习统计
- 一键清除本地学习数据

## Windows 11 快速开始

### 1. 准备 Node.js

普通用户需要安装 **Node.js 18 或更高版本**。推荐从 [Node.js 官网](https://nodejs.org/) 安装当前 LTS 版本。

安装完成后，在 CMD 或 PowerShell 中运行：

```powershell
node -v
```

看到 `v18` 或更高版本即可。

Node.js 在本项目中只负责运行本机服务：打开网页、读取本机 API 配置、代理千问请求以及在网页关闭后结束服务。网页界面本身仍然由浏览器运行。

### 2. 下载项目

不熟悉 Git 的用户：

1. 点击 GitHub 仓库右上方的 `Code`
2. 选择 `Download ZIP`
3. 下载完成后右键压缩包，选择“全部解压缩”
4. 不要直接在压缩包预览窗口中运行脚本

熟悉 Git 的用户也可以运行：

```powershell
git clone https://github.com/Neil-Mivan/HYLE-Help-You-Learn-English.git
cd HYLE-Help-You-Learn-English
```

### 3. 启动网站

日常使用推荐双击：

```text
launch.cmd
```

它会自动启动本机服务、打开网页，并在最后一个澄读网页关闭约 7 秒后结束服务。

需要查看运行日志或排查问题时，双击：

```text
start.cmd
```

保持黑色窗口开启，然后访问：

```text
http://127.0.0.1:4173
```

关闭 `start.cmd` 的黑色窗口即可停止服务。`start.cmd` 不受 PowerShell 脚本执行策略限制；`start.ps1` 仅作为备用启动方式保留。

## 配置阿里云百炼千问

不配置 API Key 也可以使用文章导入、本地排版、阅读、字号调整、高亮、笔记、文章库和阅读进度等功能。

独立 AI 翻译、千问文章翻译、AI 结构识别、语境解释和长难句拆解需要用户自己的阿里云百炼 API Key。

### 推荐配置方式

1. 在阿里云百炼创建自己的 API Key
2. 双击项目中的 `configure-api.cmd`
3. 在黑色窗口中粘贴 API Key；输入内容只显示为星号
4. 看到配置成功提示后，关闭正在运行的网站服务
5. 重新双击 `launch.cmd` 或 `start.cmd`
6. 网页右上角显示“千问翻译已连接”即配置成功

配置脚本会把 Key 写入本机的 `.env.local`。该文件已经被 `.gitignore` 排除，不应发送给他人或上传到 GitHub。

也可以点击网页右上角的“本机 API”按钮，临时连接个人 Key。用户可自行选择仅在当前浏览器会话中保存，或记住在当前浏览器中。

### 默认模型

- 普通翻译：`qwen-mt-lite`
- 单词语境义：优先 `qwen3.5-flash`
- 标题与结构识别、语境解释、长难句拆解：优先使用强模型并自动降级

默认强模型顺序定义在 `.env.example` 中。模型免费额度用尽、限流或暂不可用时，服务会尝试下一个模型。

如需使用业务空间专属地址，可以在 `.env.local` 中修改：

```env
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

## 无 API 与配置 API 的区别

| 功能 | 无千问 API | 已配置千问 API |
| --- | --- | --- |
| 文章导入与本地排版 | 可用 | 可用 |
| 文章库、字号、笔记和高亮 | 可用 | 可用 |
| 阅读位置记录与“继续阅读” | 可用 | 可用 |
| Chrome 支持时的文章内普通翻译 | 可尝试 | 可用，优先千问 |
| 独立单词、词组和句子翻译 | 不可用 | 可用 |
| AI 标题与正文结构识别 | 不可用，使用本地规则 | 可用 |
| 语境义解释和长难句拆解 | 不可用 | 可用 |

## 隐私与数据边界

- 项目没有账号系统、分析服务器、广告或第三方统计代码
- 文章、笔记、高亮、生词本和阅读历史保存在当前浏览器的 `localStorage`
- 本机配置的千问 Key 只保存在 `.env.local`
- 网页连接的个人 Key 保存在当前浏览器的会话存储或本地存储中
- 只有用户主动发起的翻译或分析请求才会向阿里云百炼发送必要文本
- 独立翻译只发送当前输入，不附带文章、笔记、阅读历史或其他学习数据
- 开启 AI 结构整理时，导入的整篇文章会发送一次；取消勾选后仅使用本地规则
- 笔记、生词本和阅读历史不会被作为翻译请求发送
- 清除浏览器站点数据或点击“我的”中的清除功能，会删除本地学习数据

不要把自己的 `.env.local`、API Key、浏览器数据目录或包含私人文章的导出内容提交到公开仓库。

## 常见问题

### 提示 “Node.js was not found”

安装 Node.js 18 或更高版本，安装后重新打开终端或重启电脑，再运行 `launch.cmd`。

### PowerShell 提示“禁止运行脚本”

不需要修改系统执行策略，直接使用：

```text
start.cmd
```

### 网页没有自动打开

保持 `start.cmd` 窗口开启，并手动访问：

```text
http://127.0.0.1:4173
```

### 配置 API 后仍显示未连接

关闭旧的服务窗口，重新运行 `launch.cmd` 或 `start.cmd`，然后刷新网页。仍失败时，检查百炼 Key、余额、模型权限和 API 地址。

### 端口 4173 已被占用

先关闭之前运行的澄读窗口。如果仍然占用，可以在 PowerShell 中临时换一个端口：

```powershell
$env:PORT=4174
node server.mjs
```

然后访问 `http://127.0.0.1:4174`。

### 关闭网页后服务没有停止

只有 `launch.cmd` 启动的自动模式会在最后一个网页关闭后自动停止。使用 `start.cmd` 时，需要手动关闭黑色窗口。

## 项目结构

```text
index.html          网页结构
styles.css          页面样式和响应式布局
app.js              阅读、翻译、笔记和本地数据逻辑
server.mjs          本机 HTTP 服务与千问 API 代理
start.cmd           持续运行和排错启动方式
launch.cmd          自动打开、自动停止的日常启动方式
configure-api.cmd   安全配置本机千问 API Key
.env.example        可复制的环境变量示例
```

项目没有第三方前端框架和 npm 运行依赖。安装 Node.js 后即可启动，不需要执行 `npm install`。
