# 澄读 · IELTS Reading

隐私优先的雅思精读工具。无需账号和数据库；可选接入阿里云百炼千问翻译 API。

## 已实现

- 粘贴英文文章并自动识别标题、整理段落
- 舒适阅读排版和字号调节
- 点击单词查看本地词典释义、音标和发音
- 框选单词、词组或句子进行浏览器内英中翻译
- 段落级全文对照翻译
- 三色高亮、选段笔记和生词本
- 本地文章库、学习统计和数据清除
- 所有文章与学习记录只保存在当前浏览器的 `localStorage`
- 可选千问翻译后端，API Key 仅保存在本机 `.env.local`
- 导入时可选用强模型自动识别标题、段落和小标题；AI 输出必须通过原文完整性校验，否则自动退回本地排版
- 单词支持按需生成语境义解释；六词以上的选区支持按需长难句拆解
- AI 学习结果保存在当前浏览器，重复查看不会再次调用 API

## 启动

最简单的方式是双击 `start.cmd`。也可以在 PowerShell 中进入本目录，然后运行：

```powershell
.\start.cmd
```

`start.cmd` 不受 PowerShell 执行策略限制。项目同时保留了 `start.ps1`，供允许本地脚本的环境使用。

浏览器访问 `http://127.0.0.1:4173`。

日常使用可双击桌面的“澄读”快捷方式。它会隐藏启动窗口、自动打开网页，并在最后一个澄读网页关闭约 7 秒后自动结束本地服务。项目中的 `launch-hidden.vbs` 与 `launch.cmd` 提供这一启动模式；`start.cmd` 仍保留为持续运行和排错模式。

翻译功能建议使用桌面版 Chrome。首次翻译时，Chrome 可能需要下载英中语言包；翻译由浏览器内置模型完成。其他浏览器仍可使用排版、词典、高亮、笔记和历史记录。

## 配置阿里云百炼翻译

1. 双击 `configure-api.cmd`。
2. 在黑色窗口中粘贴百炼 API Key；输入内容只显示为星号。
3. 配置保存后，关闭正在运行的 `start.cmd` 窗口并重新双击启动。
4. 刷新网页，右上角显示“千问翻译已连接”即配置成功。

默认使用华北 2（北京）公共 OpenAI 兼容端点和 `qwen-mt-lite`。如需使用业务空间专属 API Host，可在 `.env.local` 中修改 `DASHSCOPE_BASE_URL`。

普通翻译使用 `qwen-mt-lite`，单词语境义优先使用 `qwen3.5-flash`。标题/结构识别、语境解释和长难句拆解按 `qwen3.7-max`、Max 快照、`qwen3.7-plus`、Plus 快照、`qwen3.5-flash` 的顺序调用；遇到免费额度用尽、限流或模型暂不可用时自动切换。可通过 `.env.local` 中的 `DASHSCOPE_ANALYSIS_MODELS` 自定义顺序（英文逗号分隔）。

朋友自带 Key 模式：网页右上角可以连接各自的百炼 API Key。Key 仅保存在朋友自己的浏览器中，并随同源 HTTPS 请求临时发给后端代理；个人 Key 的请求不会进入服务端缓存。公网部署时不要上传 `.env.local`，并设置 `HOST=0.0.0.0` 和 `CLEAR_READING_REQUIRE_PERSONAL_KEY=1`，强制每位访客使用自己的 Key。服务端只公开三个前端静态文件，配置、快照和源码说明文件不能通过 URL 读取。

## 隐私边界

- 项目没有分析服务器、登录服务或第三方统计代码。
- 未配置云端翻译时，项目不会向 OpenAI 或其他翻译服务发送文章。
- 配置千问后，只有主动点击翻译、语境解释或长难句拆解的必要文本会发送给阿里云百炼；笔记、历史和生词本不会发送。
- 导入窗口默认启用 AI 结构整理，并明确提示整篇文章会发送一次；取消勾选后仅使用本地规则，不因导入而发送文章。
- Chrome 语言包的下载由浏览器管理，实际翻译在浏览器侧完成。
- 清除站点数据或点击学习页的“清除全部本地数据”，会删除本地保存的内容。
