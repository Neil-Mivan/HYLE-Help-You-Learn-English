# 澄读 · HYLE

澄读是一款适合雅思备考和日常英语学习的精读工具。把英文文章粘贴进来，就能边读边查词，标出难句，记下自己的理解。

## 可以用它做什么？

- **读文章**：自动整理标题和段落，可以调整字号。读到一半去查词，点「继续阅读」就能回到刚才的位置。
- **结合上下文查词**：点击单词，或拖选整个词组、句子查看翻译。例如，选中 *water hyacinth*，就能看到整个词组的意思「水葫芦」。
- **弄懂难句**：想知道一个词为什么这样译，可以点「为什么这样翻译？」查看依据。遇到长句，点「拆解长难句」查看主干和从句。
- **随手记录和复习**：给原文加高亮、写笔记，把想记住的词加入生词本，以后结合原句复习。
- **单独翻译**：打开「翻译」页就能直接查询。输入单词可看词性、释义和例句，输入句子可看完整译文。

## Windows 怎么开始？

[下载 Windows x64 便携版 v0.2.0](https://github.com/Neil-Mivan/HYLE-Help-You-Learn-English/releases/download/v0.2.0/HYLE-Windows-Portable-v0.2.0-x64.zip) → 右键选择「全部解压缩」→ 打开解压后的文件夹，双击 `START-HYLE.cmd`。浏览器会自动打开澄读。

新版使用 Vue 3 和 Java Spring Boot，便携包自带 Java 运行时，不用安装 Java 或 Node.js。从旧版升级时，先关闭旧版，再将新版解压到新文件夹；用原来的浏览器打开同一地址，已有文章和笔记仍可使用。开发者请看[源码启动说明](DEVELOPMENT.md)。

## 需要账号或 API Key 吗？

无需注册。阅读、笔记、高亮和生词复习都可以直接使用。需要 AI 翻译或语法分析时，在右上角点「连接 API」，填入自己的千问 API Key 即可。

文章和学习记录保存在当前浏览器。使用 AI 查词时，会将所选内容及所需上下文发送给千问；导入时若勾选「AI 结构整理」，则会发送本次导入的全文。
